# meimei
The project consists of ASCII art of Meimei the snow leopard bombing their house with broccoli. Instead of displaying the image using pixels, the program recreates the frame using text characters such as @, #, *, and +. Each character was selected according to its shape and brightness to retain the original colour. 

The project focuses specifically on creating an animation with over 100 frames rather than creating a still image, and even incorporates playback using Tkinter, Pillow, and more. 

Features: GIF-to-ASCII conversions, colour preservation, frame-by-frame animation and movement, and interactive controls.
